# Final Reflection Template

Each student should write their own reflection; do not submit identical reflections.

## My contribution
- What features, database artifacts, tests, and documentation did I personally complete?
- Which GitHub issues and pull requests show my work?

## Technical learning
- What did I learn about relational database design and 3NF?
- What did I learn about SQL joins, aggregate queries, transactions, and referential integrity?
- What did I learn about WinForms and integrating a REST API?

## Challenges and decisions
- What was the most difficult technical problem?
- How did the team resolve design or merge conflicts?
- What would I change about our architecture or workflow?

## Team collaboration
- How were responsibilities divided?
- How did code reviews improve the project?
- What would I do differently on the next group project?

## Future improvements
- What features would be appropriate after the capstone (nutrition data, family profiles, dietary filters, recurring plans, mobile access, etc.)?
- What constraints or risks would need to be addressed first?
